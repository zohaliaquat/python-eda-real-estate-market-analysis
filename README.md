# Real Estate Market Analysis - Gurugram

Exploratory data analysis of 14,000+ residential property listings in Gurugram, India, examining pricing trends, builder performance, and locality-wise rate patterns.

## Overview

This project analyzes real estate listing data to understand key market drivers such as builder positioning, locality pricing, and the relationship between price, area, and rate per sqft.

## Tools Used

Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

## Key Insights

- M3M leads in listing volume (1,845 properties); DLF has the highest average price among top builders
- Sector 42 and Sector 113 have the highest average rate per sqft (above Rs 50,000)
- Most properties are priced between Rs 1-4 crore
- Price and rate per sqft show a moderate positive correlation (0.62)

## Visualizations

Builder-wise listing volume and pricing, locality rate comparisons, price distribution, and a correlation heatmap.

## How to Run

1. Clone this repository
2. Install dependencies: `pip install pandas matplotlib seaborn jupyter`
3. Open the notebook and run all cells
